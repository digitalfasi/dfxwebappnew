# Gold Rate

## What this module does
Set and view the shop's gold rate, and watch the live market rate. This is where a "gold rate bug" would be fixed.

## Files here
- GoldRate.jsx -> the gold rate screen (set today's rate, see history and the live rate).
- goldRateService.js -> saves and loads the shop's own gold rates from the backend.
- liveRateService.js -> reads the live market gold rate feed.
