# Plan (schemes and enrollments)

## What this module does
Everything about gold savings plans. It has two parts kept in separate sub-folders.

## Key logic
- scheme/ = the plan TEMPLATES (the rules): what plans exist, how long they run, and how each contribution is valued in gold. This is the definition, not a specific customer.
- enrollment/ = a specific CUSTOMER signed up on a plan (their live membership, their payments and progress).
So "scheme" is the product on the shelf; "enrollment" is one customer's actual account on that product.
