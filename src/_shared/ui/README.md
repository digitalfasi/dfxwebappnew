# Shared UI components (`_shared/ui`)

## What this module does
The basic reusable visual pieces used to build every screen, so the app looks consistent everywhere.

## Files here
- button.jsx -> clickable buttons in their various styles.
- card.jsx -> the boxed "card" containers that group content.
- input.jsx -> text boxes and the search box.
- select.jsx -> dropdown pickers.
- badge.jsx -> the small coloured status labels (e.g. "Active", "Overdue").
- LineChart.jsx -> the simple line graph used on the dashboard and gold-rate screens.
